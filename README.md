# Proyecto Práctico II - Calculadora de materiales de construcción

Proyecto frontend realizado con HTML y CSS tomando como referencia el mockup de Figma.

## Tecnologías
- HTML5
- CSS3

## Pantallas
- Inicio de sesión
- Registro
- Menú principal
- Muro de ladrillo
- Viga de hormigón
- Columnas
- Contrapisos
- Techo
- Pisos
- Pintura
- Pantallas de resultados

## Nota
Esta versión no utiliza JavaScript. Por ello, la navegación y la presentación de resultados son estáticas. Para que los cálculos dependan de los valores escritos por el usuario se requiere JavaScript o un lenguaje de servidor.
